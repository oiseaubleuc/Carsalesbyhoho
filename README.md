# Carsalesbyhoho

Carsalesbyhoho is a WPF desktop application built in C# for managing car sales.  
The application focuses on structured data management, relational databases, and a clean desktop user interface.

---

## Features

- Manage cars, brands, and car types
- Customer management
- Sales registration
- Relational database structure
- CRUD operations (Create, Read, Update, Delete)
- Data seeding for initial setup

---

## Tech Stack

- **Language:** C#
- **Framework:** .NET (WPF)
- **Architecture:** MVVM
- **Database:** SQLite
- **ORM:** Entity Framework Core
- **Tools:** Visual Studio

---

## Project Structure

- `Models/` – Entity models (Car, Brand, Customer, Sale, etc.)
- `Views/` – WPF views (XAML)
- `ViewModels/` – Application logic and bindings
- `Data/` – Database context and configuration
- `App.xaml` – Application startup and resources

---

## Installation & Setup

### Requirements
- Windows
- .NET SDK 7.0 or higher
- Visual Studio (recommended)
